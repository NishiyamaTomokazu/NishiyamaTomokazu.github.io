ステップ４のヘルプ

■基本的な使い方
  • 認証のしかた : 「登録名を入力」に名前を入力し、「金庫の鍵を開ける」ボタンを押してください。
  • プログラムの変更 : 右下のブロックを使って、認証結果（成功・失敗）ごとのメッセージやLEDの色、点灯時間を変更できます。
  • *ステップ4ではブロックの追加・削除はできません。数値や文章の変更のみ可能です。
■オーロラクロックの接続手順
オーロラクロックを接続すると、認証結果に合わせてLEDを光らせることができます。
  • Windows/ChromeBookの場合
  • 「金庫の鍵を開ける」ボタンを押します。
  • ポップアップ画面で「HISATOMI_UD-1_....」を選択し、「接続」を押します。
  • 画面に「接続完了」と表示されます。
  • アプリからデータを送信している間、オーロラクロックのLEDが白く点灯し、その後に指定した色に変わります。
  • iPadの場合
  • オーロラクロック本体の「SW」スイッチを押しながら電源を入れ、LEDが白→赤の順に光ったらスイッチを離します。
  • アプリ画面で、「オーロラクロックと接続中」にチェックを入れ、「金庫の鍵を開ける」ボタンを押します。
  • チェックを入れる前にボタンを押してしまった場合は、電源を一度切り、再度「SWスイッチ」を押しながら電源をオンにしてください。
  • アプリからデータを送信している間は、オーロラクロックのLEDが青く点灯し、その後に指定した色が光ります。

困った時は

Q. オーロラクロックのLEDが点灯しない
A. 正しく接続されていない可能性があります。以下をご確認ください。
・Windows / ChromeBook : ケーブルの接続を再度確認し、電源を入れ直してください。
・iPad : 電池が入っているか、iPadの音量が最大になっているかを確認し、「SW」スイッチを押しながら、電源を入れ直してください。
