ステップ４のヘルプ

■基本的な使い方
  • 認証のしかた : 「登録名を入力」に名前を入力し、「金庫の鍵を開ける」ボタンを押してください。
  • プログラムの変更 : 右下のブロックを使って、認証の成功時・失敗時の「しゃべるメッセージ」や「LEDの色、点灯時間」を変更できます。
  • *ステップ4ではブロックの追加・削除はできません。内容の変更のみ可能です。
  • オーロラクロックが接続されていると、認証されたときとされなかったときにLEDを点灯させることができます。
■オーロラクロックの接続について
オーロラクロックを接続すると、認証結果にあわせてLEDを光らせることができます。お使いの端末に合わせて接続してください。
  • Windows/ChromeBookの場合
  • 最初に「金庫の鍵を開ける」ボタンを押すと、ウィンドウが表示され「HISATOMI_UD-1_・・・」と表示されるので、これを選択して、下の「接続」ボタンを押してください。
  • 正しく接続されると画面に「接続完了」と表示されます。
  • アプリからデータを送信している間、オーロラクロックのLEDが白く点灯し、その後に指定した色に変わります。
  • iPadの場合
  • 本体の「SWスイッチ」を押しながら、電源を入れて、LEDが白、赤の順に点灯したあと、スイッチを離してください。
  • オーロラクロックへプログラムを転送する時は、「オーロラクロックと接続中」にチェックを入れた後、「金庫の鍵を開ける」ボタンを押してください。
  • チェックを入れる前に、ボタンを押した場合は、オーロラクロックの電源を一度オフにして、再度「SWスイッチ」を押しながら電源をオンにしてください。
  • アプリからデータを送信している間は、オーロラクロックのLEDが青く点灯し、その後に指定した色が光ります。

ブロックはメッセージの修正やLEDの点灯色や時間の変更だけができます。

LEDは指定した点灯色の前に白色（または青色）が点灯します。これは、Webアプリからデータ受信中を表すために点灯しております。

困った時は

Q. オーロラクロックのLEDが点灯しない
A. オーロラクロックが正しく接続されていない可能性があります。
・Windows / ChromeBookの場合は、ケーブルの接続を確認した後、電源を入れ直してください。
・iPadの場合は、本体に電池が入っていることを確認した後、「SW」ボタンを押しながら、電源を入れ直してください。
　また、iPadの音量が最大になっていることを確認してください。
