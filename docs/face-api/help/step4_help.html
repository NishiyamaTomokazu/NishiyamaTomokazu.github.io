ステップ４のヘルプ

  • 「登録名を入力」に名前を入力し、「金庫の鍵を開ける」を押して認証してください。
  • 右下のブロックで、認証されたときとされなかったときのメッセージを変更することができます。
  • オーロラクロックが接続されていると、認証されたときとされなかったときにLEDを点灯させることができます。
  • オーロラクロックと接続されていると「接続中」と表示されます。
  • ※ステップ４では、ブロックの追加や削除はできません。

ブロックはメッセージの修正やLEDの点灯色や時間の変更だけができます。

LEDは指定した点灯色の前に白色が点灯します。これは、Webアプリからデータ受信中を表すために点灯しております。

困った時は

Q. オーロラクロックのLEDが点灯しない
A. オーロラクロックが正しく接続されていない可能性があります。
・Windows / ChromeBookの場合は、ケーブルの接続を確認した後、電源を入れ直してください。
・iPadの場合は、本体に電池が入っていることを確認した後、「SW」ボタンを押しながら、電源を入れ直してください。
