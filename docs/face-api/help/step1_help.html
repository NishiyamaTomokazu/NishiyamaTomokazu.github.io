ステップ１のヘルプ

  • 「カメラを起動する」ボタンを押して、カメラの使用を許可してください。
  • カメラに自分の顔が映るようにしてください。
  • 「登録する名前を入力」に名前を入力し、「この顔を登録する」ボタンを押すと、顔が登録されます。

困った時は

Q. カメラが起動しない
A. カメラの使用を許可してください。ブラウザのアドレスバーにある鍵マークをクリックして、カメラの使用を許可してください。
または、ブラウザの「設定」> 「プライバシーとセキュリティ」 > 「サイトの設定」 > 「カメラ」からカメラの使用を許可してください。

Q. 顔が登録できない
A. 顔がはっきりと映るようにしてください。顔に青い枠が表示されていると登録可能です。
