ステップ５のヘルプ

  • 認証のしかた : 「登録名を入力」に名前を入力し、「金庫の鍵を開ける」ボタンを押してください。
  • プログラムの変更 : 右下のブロックを使って、認証結果（成功・失敗）ごとのメッセージやLEDの色、点灯時間を変更できます。
  • 部品の追加 : 「部品を開く」を押すと、使えるブロックが表示されます。これらを組み合わせて、オーロラクロックの光や音を自由に追加できます。

オーロラクロックがデータ受信中は、指定した色の前にLEDが一時的に白（または青）に点灯します。これは、本体がデータ受信中であることを表します。

困った時は

Q. オーロラクロックのLEDが点灯しない
A. 正しく接続されていない可能性があります。以下をご確認ください。
・Windows / ChromeBook : ケーブルの接続を再度確認し、電源を入れ直してください。
・iPad : 電池が入っているか、iPadの音量が最大になっているかを確認し、「SW」スイッチを押しながら、電源を入れ直してください。
