試してみよう

カメラ画像の下に「特徴点（顔のライン）を表示する」にチェックを入れてみましょう。画面上に顔の特徴点が表示されます。
顔認証のプログラムは、この特徴点を調べて、認証を行っています。
💡 こんな実験もしてみよう
顔の一部を手で隠しても、顔認証が成功するかどうか試してみましょう。

顔の一部を隠しても、顔認証が成功することがあります。
顔の特徴点は、顔の一部が隠れていても、残りの特徴点から本人かどうかを判断できる場合があります。
